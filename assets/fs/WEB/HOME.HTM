Bordify Web

A small, native HTML reader for pages stored on the Bordify disk and HTTP or HTTPS pages on the network.

No host browser is involved. The text below is rendered by the kernel from a real file in WEB/HOME.HTM.

HTTP and HTTPS pages load through the emulated Intel e1000 adapter. HTTPS connections use TLS 1.2 and the installed root certificate authorities.
