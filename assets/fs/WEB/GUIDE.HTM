Using Bordify

The desktop has three shortcuts in the top left. Click one to open its window.

Windows

  • Drag a window by its title bar.
  • Use the round close button to put it away.
  • Click a window to bring it to the front.

Files

Double-click a folder to enter it. Double-click a text file to read it. The New, Folder and Delete buttons change the FAT16 disk directly.

Settings

Choose a theme. Light is the default paper-white look. Changes are saved immediately to SYSTEM/SETTINGS.CFG.

Network

The web app can open HTTP and HTTPS pages. HTTPS uses TLS 1.2 with the built-in root certificate authorities; the VM needs its network adapter connected.

Keyboard

F1 opens Files. F2 opens web. F3 opens Settings. Escape closes menus and dialogs.
