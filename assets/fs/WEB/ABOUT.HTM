About Bordify

Bordify is a hand-made 32-bit x86 operating system. It has its own boot path, interrupt handling, memory allocator, framebuffer graphics, window manager, disk driver and FAT16 filesystem.

The small details

  • Multiboot2 boot through GRUB
  • 1024 x 768, 32-bit linear framebuffer
  • PS/2 keyboard and mouse
  • PIT clock and CMOS real-time clock
  • ATA PIO disk access
  • Read and write FAT16

The interface is drawn pixel by pixel. DejaVu glyphs are baked into the kernel as small anti-aliased bitmaps.
